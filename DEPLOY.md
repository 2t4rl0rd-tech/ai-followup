# Deploy FollowUp Brain

## Stato
- Frontend + backend locali pronti
- Repository GitHub aggiornato
- GitHub Pages non basta per il backend Node

## Serve per andare online davvero
- un host Node, per esempio Render, Fly.io, Railway o una VPS
- collegare il repo GitHub
- avviare `npm start`

## Comando locale
```bash
node server.js
```

## URL locale
http://localhost:3000
