# Roadmap FollowUp Brain

## Fase 1, validazione
- 5 conversazioni con potenziali clienti
- capire quale formato usano di più, chat, email, call o note
- scegliere un solo flusso iniziale

## Fase 2, MVP
- input semplice
- motore di sintesi / estrazione azioni
- output pronto da usare
- storico minimo

## Fase 3, vendita
- landing chiara
- demo breve
- prezzo visibile
- canale di contatto diretto

## Fase 4, crescita
- template specifici per nicchia
- pacchetti premium
- rinnovi mensili
- richiami e follow-up automatici
